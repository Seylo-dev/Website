---
title: What's new in 0.2.8
description: Move the panel to another server from Settings, with your nodes following by themselves.
---

0.2.8 updates a 0.2.7 panel like any other release: **Settings → Updates** shows it with its changelog, and **Update to 0.2.8** updates the panel first, then each node. Nothing needs to be run on the servers, and there is no database step to do by hand.

## New

- **Move the panel to another server.** In **Settings → General**, the owner picks one of the nodes and the panel moves there: its database, keys, branding and uploads, and the image registry. Every node follows by itself with the same pin, so nothing has to be joined again, and any failure before the switch leaves the old panel running as it was. The old server keeps a stopped copy until you delete it. See [Moving the panel to another server](/self-hosting/the-panel#moving-the-panel-to-another-server).

## Improved

- **GitHub page.** A connected account can switch to a personal access token, or replace its token, from **Settings → GitHub** (before, only after a disconnect).
- **MCP setup for Claude.** The Claude Code command adds the panel for every project (`--scope user`), and **Copy the URL and open Claude** copies the server URL on the way to Claude's connectors page. Claude has no install link to do more.

## Fixed

- **MCP sign-in from a browser ended on "Not allowed".** The sign-in pages told browsers to send no referrer, which by the web standard also makes them send `Origin: null` on the form posts, and the panel refused those as coming from another site. Every AI tool's sign-in through the browser now finishes.

- **The panel domain could go active for another server.** A domain proxied by Cloudflare whose record still pointed at another server (an old panel, or any app answering `{"status":"ok"}` on `/api/health`) passed the domain check, so `http://<ip>:3000` redirected people there. The check now asks the domain a one-time question only this panel can answer.

## After the update

- Nodes need 0.2.8 too before they can take the panel or follow it; the update does that.
